# Sales Analytics Dashboard (Console) 📊

## 📌 Project Overview

The Sales Analytics Dashboard is a console-based Python project that analyzes monthly product sales using **NumPy**. It calculates important business statistics, including total revenue, average revenue, profit percentage, and product sales performance.

This project demonstrates how NumPy can be used to perform efficient numerical calculations and extract meaningful insights from sales data.

## 🎯 Objectives

- Analyze monthly sales data using NumPy.
- Calculate revenue and profit for each product.
- Apply arithmetic operations to NumPy arrays.
- Calculate statistical measurements.
- Identify the best-selling and worst-selling products.
- Display the top 5 products based on revenue.

## 🛠️ Technologies Used

- **Python** — Programming language
- **NumPy** — Numerical calculations and statistical analysis

## 📋 Dataset

The dataset contains the following information:

| Attribute | Description |
|---|---|
| Product ID | Unique identifier for each product |
| Monthly Sales | Number of units sold during the month |
| Selling Price | Selling price per unit |
| Total Monthly Cost | Total cost associated with the product |

The program includes sample data and also allows users to enter their own product data.

**Revenue** and **profit** are calculated using the following formulas:

Revenue = Monthly Sales × Selling Price

Profit = Revenue − Total Monthly Cost
